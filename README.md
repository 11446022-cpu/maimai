# maimai 日本版樂曲資料庫

網站為提供使用者進行查詢/篩選樂曲作為使用

GitHub Actions 在部署時會下載 SEGA 日本版官方現行資料 https://maimai.sega.jp/data/maimai_songs.json，再部署到 GitHub Pages。現行資料快照不保證包含已刪除歌曲；來源未提供的譜面作者及日期不會自行補造。

## 啟用 Pages
進入 Settings → Pages，將 Build and deployment 的 Source 設為 GitHub Actions。推送 main 後，Actions 自動部署。網址:file:///C:/Users/willy/Downloads/maimai_song_database_updated.html
本專案為學習用途，非 SEGA 官方網站。
